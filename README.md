## Descrição da Proposta
Trabalho prático da disciplina de Algoritmos focado na implementação do autômato celular *Game of Life* (John Conway), utilizando uma matriz para representar o mundo e aplicando as regras de evolução populacional a cada geração.

## Instruções de Compilação e Execução
O programa segue o padrão *C++*.

### Compilação (via Terminal / G++)
```bash
g++ main.cpp -o jogo_da_vida

```

### Execução

```
./jogo_da_vida
```
